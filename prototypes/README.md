# Prototypes

Throwaway code that answers **one** design question at high fidelity. Built with `/prototype`, kept on its own branch, never merged. This page on `main` is the index.

How to open one:

```powershell
git fetch origin
git switch prototype/<name>
start prototypes/<name>/index.html        # Windows; opens in the default browser
```
